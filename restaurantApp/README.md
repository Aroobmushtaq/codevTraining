# Restaurant MERN WebApp

🔗 **Live Demo:** https://remarkable-babka-0dbfaa.netlify.app/

---

##  About

A full-stack restaurant web application built using the MERN stack. It includes two panels: an **Admin Panel** to manage menu and orders, and a **User Panel** for browsing and ordering food.

---

##  Tech Stack

* MongoDB
* Express.js
* React.js
* Node.js
